# EstateFlow v1.0 Property Domain Decision Request

## Purpose

Engineering requires Product Owner decisions before implementing Property domain behaviour.

## Decisions Required

### Decision PD-003 — Property Lifecycle

Questions requiring Product Owner decision:
- Does Property have lifecycle states?
- What states exist?
- What transitions are allowed?
- What events cause transitions?

### Decision PD-004 — Property Business Rules

Questions requiring Product Owner decision:
- What makes a Property valid?
- What fields are mandatory?
- What invariants must always hold?
- What rules govern Property changes?

### Acceptance Boundary

Engineering will implement only approved decisions.

### Deferred Items

- No lifecycle implementation
- No validation implementation
- No business rule implementation

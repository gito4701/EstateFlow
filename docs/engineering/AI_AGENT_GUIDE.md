# AI Agent Guide

## Purpose
This guide defines how AI agents may operate within EstateFlow while respecting human governance and repository rules.

## Guiding Principle
- Documentation precedes implementation. Governance precedes code. Architecture precedes frameworks.

## Scope
- Applies to AI agents engaged in repository analysis, documentation generation, and authorized task support.
- Does not authorize implementation of production artifacts or architectural changes without explicit human approval.

## Authority
- AI agents must follow human instructions and the approved governance documents.
- Agents shall not make business decisions or architectural decisions.
- Agents shall not expand scope beyond authorized tasks.

## Responsibilities
- Agents must document assumptions, sources, and reasoning when producing or modifying repository content.
- Agents must reference the engineering constitution and related governance documents for mandatory requirements.
- Agents shall treat this guide as part of the repository's governance baseline.

## Mandatory Requirements
- AI agents must only produce content within approved scope.
- Agents must not introduce code, tests, infrastructure, or implementation artifacts.
- Any recommendation for additional work must be reported, not implemented.

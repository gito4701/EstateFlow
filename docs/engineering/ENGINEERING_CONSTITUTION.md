# Engineering Constitution

## Purpose
This document defines the governance principles and mandatory rules for EstateFlow engineering activities.

## Scope
- Applies to all engineers and authorized AI agents engaged in repository foundation, planning, and documentation.
- Does not authorize implementation work beyond approved documentation.

## Principles
- Documentation precedes implementation. Governance precedes code. Architecture precedes frameworks.
- Design decisions must be captured before execution.
- Work must remain within authorized scope.

## Ownership
- Primary owner: Engineering leadership or designated repository steward.
- Secondary owner: Documentation steward.

## Update Responsibility
- Updates shall be proposed by engineering leadership or appointed documentation owners.
- Updates must be reviewed and approved before being committed.
- The document shall be versioned through repository history.

## Mandatory Requirements
- All engineering work must reference this constitution for governance guidance.
- Engineering decisions must follow documented principles and avoid unauthorized scope expansion.
- This document shall not duplicate authority defined in external project charters; it may reference related governance documents instead.
